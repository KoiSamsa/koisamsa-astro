# koisamsa-astro

Web de Koi Samsa en Astro. Hosting: Cloudflare Pages. Contenido: markdown en `src/content/`.

- `npm run dev` — desarrollo (`/keystatic` edita en local)
- `npm run build` — build para Cloudflare (`dist/`)

Panel de contenidos y despliegue: ver `KEYSTATIC.md`.
Diseño: MUDA (`public/muda/` cuando se conecte). Las plantillas se diseñan por prototipo HTML y se traducen mecánicamente a Astro.
